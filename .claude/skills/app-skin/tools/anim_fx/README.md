# 场景动效插件

每个门派的专属动效写成这里的一个 `<名字>.py`，在 `../scene-anim.d/<门派 id>.json` 里用 `"effects": [{"fx": "<名字>", ...}]` 引用。
接口和可用工具见 `../animate-scene.py` 开头的说明。规则：

- 只用 numpy / Pillow，结果确定（随机数只用传进来的 rng），所有运动在一个循环里是整数周期，`t=1` 和 `t=0` 画面一样。
- 底图不改，只往上叠；粒子要在浅色和深色场景上都看得见（必要时加一圈很淡的深色或浅色边）。
- 一个插件只做一种效果，名字说清楚是什么（`ginkgo_leaves`、`bell_rings`、`butterflies` …）。各门派互不复用。
